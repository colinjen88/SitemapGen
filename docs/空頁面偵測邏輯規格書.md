# 空頁面偵測邏輯規格書

本文件描述如何判斷 PM 系統中的頁面是否為「空頁面」，適用於 Sitemap 產生器與連結檢查工具。

---

## 一、空商品頁 (product-detail.php)

### 適用範圍
- URL 包含 `/product-detail.php`

### 判斷流程

1. **定位 breadcrumb**
   - 找到頁面中的 `.breadcrumb` 元素
   - 若找不到 → **預設為有效頁面**

2. **定位商品資訊容器**
   - 從 `.breadcrumb` 往後尋找第一個 `<div class="row">`
   - 若找不到 → **預設為有效頁面**

3. **檢查商品標題**
   - 在該 `.row` 內尋找 `.product-title` 元素
   - 取得其 `innerText`，去除前後空白

4. **最終判斷**
   - 若 `.product-title` 不存在 → **空商品頁**
   - 若 `.product-title` 存在但 `innerText.strip()` 為空字串 → **空商品頁**
   - 若 `.product-title` 存在且有內容 → **有效頁面**

### 程式碼範例 (Python + BeautifulSoup)

```python
def is_empty_product_page(soup):
    """
    判斷 product-detail.php 是否為空商品頁
    回傳: (is_empty: bool, reason: str)
    """
    breadcrumb = soup.find(class_='breadcrumb')
    if not breadcrumb:
        return (False, "找不到 breadcrumb，預設為有效頁面")
    
    row_div = breadcrumb.find_next('div', class_='row')
    if not row_div:
        return (False, "找不到 .row，預設為有效頁面")
    
    product_title = row_div.select_one('.product-title')
    if not product_title:
        return (True, "找不到 .product-title")
    
    title_text = product_title.get_text(strip=True)
    if not title_text:
        return (True, ".product-title 為空")
    
    return (False, f"商品名稱: {title_text}")
```

## 二、空商品列表頁 (menu.php)

### 適用範圍
- URL 包含 `/menu.php`

### 判斷流程

1. **定位 breadcrumb**
   - 找到頁面中唯一的 `<nav class="breadcrumb">`
   - 若找不到 → **預設為有效頁面**

2. **定位商品列表容器**
   - 從 `<nav class="breadcrumb">` 往後尋找第一個 `<div class="row">`
   - 此為商品列表容器
   - 若找不到 → **預設為有效頁面**

3. **檢查商品相關元素**
   - 在容器內搜尋：
     - `a[href*="product-detail.php"]` (商品連結)
     - `.card` (商品卡片)
   - 若存在任一元素 → **有效頁面**

4. **檢查容器文字內容**
   - 取得容器的 `innerText`，去除所有空白字元
   - 若有內容 → **有效頁面**

5. **檢查分頁資訊**
   - 搜尋頁面文字是否包含 `0-0/0` 模式
   - 此為「0 筆紀錄」的特徵

6. **最終判斷**
   - 若同時滿足以下條件 → **空商品列表頁**：
     - 容器內無商品相關元素
     - 容器 `innerText.strip()` 為空
   - 其他情況 → **有效頁面**

### 程式碼範例 (Python + BeautifulSoup)

```python
import re

def is_empty_menu_page(soup):
    """
    判斷 menu.php 是否為空商品列表頁
    回傳: (is_empty: bool, reason: str)
    """
    breadcrumb = soup.find('nav', class_='breadcrumb')
    if not breadcrumb:
        return (False, "找不到 breadcrumb，預設為有效頁面")
    
    row_div = breadcrumb.find_next('div', class_='row')
    if not row_div:
        return (False, "找不到商品列表容器 .row，預設為有效頁面")
    
    # 檢查商品相關元素
    product_links = row_div.select('a[href*="product-detail.php"]')
    cards = row_div.select('.card')
    if product_links or cards:
        return (False, f"發現 {len(product_links)} 個商品連結, {len(cards)} 個卡片")
    
    # 檢查容器文字
    inner_text = row_div.get_text(strip=True)
    if inner_text:
        return (False, f"列表有內容: {inner_text[:50]}...")
    
    # 檢查分頁資訊
    page_text = soup.get_text()
    if re.search(r'0-0/0', page_text):
        return (True, "分頁顯示 0-0/0，且列表為空")
    
    return (True, "商品列表容器為空")
```

## 三、快速參考表

| 頁面類型 | URL 特徵 | 定位起點 | 判斷元素 | 空頁面條件 |
|---------|---------|---------|---------|-----------|
| 商品頁 | `/product-detail.php` | `.breadcrumb` | `.row .product-title` | 不存在或內容為空 |
| 列表頁 | `/menu.php` | `nav.breadcrumb` | `.row` 內的商品元素 | 無商品元素且容器為空 |

---

## 四、注意事項

1. **不要依賴側欄**：左側分類樹等內容不參與判斷，只以 breadcrumb 為定位起點。

2. **預設為有效**：當無法確定結構時（如找不到 breadcrumb），應預設為有效頁面，避免誤判。

3. **分頁資訊是輔助判斷**：`0-0/0` 模式可作為空列表的佐證，但非必要條件。

4. **商品連結優先**：只要發現任何 `product-detail.php` 連結，即可判定為有效頁面。
