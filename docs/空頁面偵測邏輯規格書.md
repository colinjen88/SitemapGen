# 空頁面偵測邏輯規格書

本文件描述如何判斷 PM 系統中的頁面是否為「空頁面」，適用於 Sitemap 產生器與連結檢查工具。

---

## 零、設定方式 (v2.16+)

從 v2.16 版本開始，空頁面偵測邏輯**可透過設定檔調整**，無需修改程式碼。

### 設定檔位置
- `setup_rules/config.json` (使用者自訂)
- `setup_rules/config_default.json` (預設值)

### 設定項目

```json
"empty_page_detection": {
    "product_detail": {
        "url_pattern": "/product-detail.php",
        "breadcrumb_selector": ".breadcrumb",
        "container_selector": "div.row",
        "title_selector": ".product-title"
    },
    "product_list": {
        "url_pattern": "/menu.php",
        "breadcrumb_selector": "nav.breadcrumb",
        "container_selector": "div.row",
        "product_link_selector": "a[href*='product-detail.php']",
        "card_selector": ".card",
        "pagination_empty_pattern": "0-0/0"
    }
}
```

### 設定說明

| 設定項 | 說明 |
|--------|------|
| `url_pattern` | 用於判斷頁面類型的 URL 特徵 |
| `breadcrumb_selector` | 定位起點的 CSS 選擇器 |
| `container_selector` | 主要內容容器的選擇器 (目前僅支援 `div.xxx` 格式) |
| `title_selector` | 商品標題的 CSS 選擇器 |
| `product_link_selector` | 商品連結的 CSS 選擇器 |
| `card_selector` | 商品卡片的 CSS 選擇器 |
| `pagination_empty_pattern` | 空列表分頁的特徵文字 (正規表達式) |

## 一、空商品頁 (product-detail.php)

### 適用範圍
- URL 包含 `url_pattern` 設定值 (預設: `/product-detail.php`)

### 判斷流程

1. **定位 breadcrumb**
   - 使用 `breadcrumb_selector` 找到元素
   - 若找不到 → **預設為有效頁面**

2. **定位商品資訊容器**
   - 從 breadcrumb 往後尋找 `container_selector` 指定的元素
   - 若找不到 → **預設為有效頁面**

3. **檢查商品標題**
   - 在容器內尋找 `title_selector` 元素
   - 取得其 `innerText`，去除前後空白

4. **最終判斷**
   - 若標題元素不存在 → **空商品頁**
   - 若標題元素存在但 `innerText.strip()` 為空字串 → **空商品頁**
   - 若標題元素存在且有內容 → **有效頁面**

### 程式碼範例 (Python + BeautifulSoup)

```python
def is_empty_product_page(soup, config):
    """
    判斷 product-detail.php 是否為空商品頁
    回傳: (is_empty: bool, reason: str)
    """
    p_cfg = config.get('empty_page_detection', {}).get('product_detail', {
        "breadcrumb_selector": ".breadcrumb",
        "container_selector": "div.row",
        "title_selector": ".product-title"
    })
    
    breadcrumb = soup.select_one(p_cfg['breadcrumb_selector'])
    if not breadcrumb:
        return (False, f"找不到 {p_cfg['breadcrumb_selector']}，預設為有效頁面")
    
    container_cls = p_cfg['container_selector'].replace('div.', '').replace('.', '')
    row_div = breadcrumb.find_next('div', class_=container_cls)
    if not row_div:
        return (False, f"找不到 {p_cfg['container_selector']}，預設為有效頁面")
    
    product_title = row_div.select_one(p_cfg['title_selector'])
    if not product_title:
        return (True, f"找不到 {p_cfg['title_selector']}")
    
    title_text = product_title.get_text(strip=True)
    if not title_text:
        return (True, f"{p_cfg['title_selector']} 為空")
    
    return (False, f"商品名稱: {title_text}")
```

## 二、空商品列表頁 (menu.php)

### 適用範圍
- URL 包含 `url_pattern` 設定值 (預設: `/menu.php`)

### 判斷流程

1. **定位 breadcrumb**
   - 使用 `breadcrumb_selector` 找到元素
   - 若找不到 → **預設為有效頁面**

2. **定位商品列表容器**
   - 從 breadcrumb 往後尋找 `container_selector` 指定的元素
   - 若找不到 → **預設為有效頁面**

3. **檢查商品相關元素**
   - 在容器內搜尋：
     - `product_link_selector` (商品連結)
     - `card_selector` (商品卡片)
   - 若存在任一元素 → **有效頁面**

4. **檢查容器文字內容**
   - 取得容器的 `innerText`，去除所有空白字元
   - 若有內容 → **有效頁面**

5. **檢查分頁資訊**
   - 使用 `pagination_empty_pattern` 搜尋頁面文字
   - 此為「0 筆紀錄」的特徵

6. **最終判斷**
   - 若同時滿足以下條件 → **空商品列表頁**：
     - 容器內無商品相關元素
     - 容器 `innerText.strip()` 為空
   - 其他情況 → **有效頁面**

### 程式碼範例 (Python + BeautifulSoup)

```python
import re

def is_empty_menu_page(soup, config):
    """
    判斷 menu.php 是否為空商品列表頁
    回傳: (is_empty: bool, reason: str)
    """
    l_cfg = config.get('empty_page_detection', {}).get('product_list', {
        "breadcrumb_selector": "nav.breadcrumb",
        "container_selector": "div.row",
        "product_link_selector": "a[href*='product-detail.php']",
        "card_selector": ".card",
        "pagination_empty_pattern": "0-0/0"
    })
    
    breadcrumb = soup.select_one(l_cfg['breadcrumb_selector'])
    if not breadcrumb:
        return (False, f"找不到 {l_cfg['breadcrumb_selector']}，預設為有效頁面")
    
    container_cls = l_cfg['container_selector'].replace('div.', '').replace('.', '')
    row_div = breadcrumb.find_next('div', class_=container_cls)
    if not row_div:
        return (False, f"找不到商品列表容器 {l_cfg['container_selector']}，預設為有效頁面")
    
    # 檢查商品相關元素
    product_links = row_div.select(l_cfg['product_link_selector'])
    cards = row_div.select(l_cfg['card_selector'])
    if product_links or cards:
        return (False, f"發現 {len(product_links)} 個商品連結, {len(cards)} 個卡片")
    
    # 檢查容器文字
    inner_text = row_div.get_text(strip=True)
    if inner_text:
        return (False, f"列表有內容: {inner_text[:50]}...")
    
    # 檢查分頁資訊
    page_text = soup.get_text()
    if re.search(l_cfg['pagination_empty_pattern'], page_text):
        return (True, f"分頁顯示 {l_cfg['pagination_empty_pattern']}，且列表為空")
    
    return (True, "商品列表容器為空")
```

## 三、快速參考表

| 頁面類型 | 設定區塊 | URL 特徵 | 定位起點 | 判斷元素 | 空頁面條件 |
|---------|---------|---------|---------|---------|-----------|
| 商品頁 | `product_detail` | `/product-detail.php` | `.breadcrumb` | `.product-title` | 不存在或內容為空 |
| 列表頁 | `product_list` | `/menu.php` | `nav.breadcrumb` | 商品連結/卡片 | 無商品元素且容器為空 |

---

## 四、注意事項

1. **不要依賴側欄**：左側分類樹等內容不參與判斷，只以 breadcrumb 為定位起點。

2. **預設為有效**：當無法確定結構時（如找不到 breadcrumb），應預設為有效頁面，避免誤判。

3. **分頁資訊是輔助判斷**：`pagination_empty_pattern` 可作為空列表的佐證，但非必要條件。

4. **商品連結優先**：只要發現任何符合 `product_link_selector` 的連結，即可判定為有效頁面。

5. **設定優先順序**：程式會優先讀取 `config.json`，若無設定則使用程式內建的預設值。

## 五、如何針對不同網站自訂規則

如果要爬取的網站使用不同的 DOM 結構，只需修改 `config.json`：

### 範例：假設目標網站使用 `.breadcrumbs` 和 `.item-title`

```json
"empty_page_detection": {
    "product_detail": {
        "url_pattern": "/product/",
        "breadcrumb_selector": ".breadcrumbs",
        "container_selector": "div.product-info",
        "title_selector": ".item-title"
    },
    "product_list": {
        "url_pattern": "/category/",
        "breadcrumb_selector": ".breadcrumbs",
        "container_selector": "div.products-grid",
        "product_link_selector": "a.product-link",
        "card_selector": ".product-card",
        "pagination_empty_pattern": "No products found"
    }
}
```
