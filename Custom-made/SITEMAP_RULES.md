# Sitemap Generator 規則說明 (Reference)

> **注意**：此檔案僅供參考。實際的規則設定請透過 GUI 介面的「客製化設定」進行修改，設定值會儲存於 `setup_rules/config.json`。

## 預設網址收錄規則

### 1. 首頁網址
- 只保留一個首頁網址（以 `START_URL` 為準，結尾自動補 `/`）。
- 排除首頁變體（如 `/index.php`），只留標準首頁。
- Priority: `1.0`

### 2. 權重設定（Priority）
預設的權重分配如下（可於 GUI 調整）：

- **首頁**：`1.0`
- **商品頁**：`0.8`
- **分類頁**：`0.8`
- **文章頁**：`0.7`
- **關於頁**：`0.6`
- **其他頁面**：`0.5`

### 3. 排除規則
預設排除以下路徑（可於 GUI 新增/移除）：

- `/login`
- `/admin`
- `/cart`
- `/account`

### 4. 其他邏輯
- **去重**：自動去除重複網址。
- **同源策略**：只收錄同網域網址。
- **參數過濾**：
  - 支援自訂正則表達式過濾規則（如排除 `page=1`）。
